# 小哭包和宝宝的周末旅行日记 · Travel Diary

> A warm, hand-drawn scrapbook travel diary built for couples.
> 一本专为情侣设计的复古手账风周末旅行日记网站。

---

## 📖 项目简介

**Travel Diary** 是一个轻量级、手账插画风格的情侣周末旅行记录网站。
前端采用原生现代 Web 技术构建，无需复杂的前端编译流程；后端基于 Python 原生轻量服务与 SQLite，支持旅行路线故事化展现、独家相册与多章节互动感言留言墙。

---

## ✨ 核心特性

- **🎨 动态随机手绘封面**：每次刷新或访问时，随机呈现 5 组手绘插画主题（海边轮船、城市霓虹、江畔夕阳、烟火夜市、星空帐篷）。
- **🗺️ 多章节路线故事集**：支持按活动分期展现（如 Vol.01 重庆江景游玩路线），以竖版连环画呈现真实游玩轨迹。
- **💌 互动感言留言墙**：支持发表带有不同情绪心情（💕、🥰、🌟 等）的拍立得便签，按活动章节独立存储。
- **📷 独家游玩相册**：支持相片瀑布流排版与全屏大图预览。
- **📱 响应式手账排版**：全面适配手机移动端与桌面大屏，内嵌手绘纸张肌理、微动效与柔和阴影，还原真实纸质手账质感。
- **⚡ 零外部运行依赖**：前后端均不依赖大型重量级框架（无庞大 `node_modules`，后端纯 Python 标准库），极轻极快。

---

## 🛠️ 技术架构

| 模块 | 技术选型 | 说明 |
| :--- | :--- | :--- |
| **前端界面** | HTML5 / Modern CSS / Vanilla JS | 纯原生实现，无需 Webpack / Vite 打包构建 |
| **后端 API** | Python 3 (`http.server` + `sqlite3`) | 原生轻量 RESTful API，零外部 pip 依赖 |
| **数据持久化** | SQLite 3 | 轻量嵌入式数据库，实现留言与相册数据持久化 |
| **本地开发** | `preview.py` | 本地独立预览服务器（集成场景随机化与本地沙箱数据库） |
| **运维部署** | Nginx + Systemd + `deploy.py` | SFTP 增量同步、配置热重载与公网健康自检 |

## 🚀 快速上手

### 1. 本地预览开发

本项目无需安装复杂的 node 环境或第三方 Python 库，直接运行系统 Python 即可：

```bash
# 启动本地预览服务（会自动打开浏览器）
python preview.py
```

* 服务将在本地 `http://127.0.0.1:8080` 启动；
* 脚本会自动创建 `diary_local.db` 本地独立数据库，本地调试留言与上传完全隔离，不影响线上真实数据；
* 预览满意后，按 `Ctrl + C` 退出。

### 2. 云端部署上线

1. 复制配置模板并填入服务器连接信息：
   ```bash
   cp .env.example .env
   # 在 .env 中填入云服务器实际的 SSH_HOST、SSH_USER、SSH_PASS
   ```

2. 运行一键推送脚本：
   ```bash
   python deploy.py
   ```
   脚本将全自动完成：
   * 前端静态文件与后端代码增量同步；
   * Nginx 配置校验与平滑热重载；
   * 后端 systemd 守护进程重启；
   * 公网可用性与 API 健康度自检。

## 📌 如何添加新旅行篇章（例：Vol.02）

1. **准备插画**：将新篇章的 3 篇竖版路线插画放入 `site/assets/`（如 `story-vol2-1.webp` 等）；
2. **点亮卡片**：打开 `site/index.html`，找到下一篇章的卡片，将 `locked` 类名移除，并填入新标题与图片路径；
3. **一键同步**：运行 `python deploy.py`，云端几秒内即可上线新篇章，并自动挂载属于新篇章的独立留言板。
